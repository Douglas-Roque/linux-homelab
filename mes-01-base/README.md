# Mês 1 — Ubuntu Server 24.04 LTS Minimal

## Objetivo
Instalação do servidor em hardware físico e primeiros
passos com Linux.

## Ambiente
- SO: Ubuntu Server 24.04 LTS (minimized)
- Hardware: Desktop dedicado
- Acesso remoto: SSH via Windows Terminal

## O que foi feito
- [x] Instalação do Ubuntu Server Minimal
- [x] Configuração de acesso SSH pelo Windows
- [x] Instalação de pacotes essenciais
- [x] Configuração de fuso horário (America/Sao_Paulo)
- [x] Script de health check do servidor

## Comandos aprendidos
| Comando | O que faz |
|---|---|
| `ip a` | Mostra IP e interfaces de rede |
| `df -h` | Uso de disco |
| `free -h` | Uso de memória |
| `uptime` | Tempo ligado |
| `sudo apt update` | Atualiza lista de pacotes |
| `sudo apt upgrade` | Atualiza pacotes instalados |
